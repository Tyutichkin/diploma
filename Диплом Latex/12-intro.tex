\Introduction

Рост числа задач, привязанных одновременно к адресу и временному окну, делает ручное планирование маршрута трудоемким и подверженным ошибкам, что формирует потребность в инструментах автоматизированного планирования.

Существующие цифровые решения представлены либо менеджерами задач, ориентированными на учет перечня дел без учета пространственного
фактора, либо навигационными сервисами, формирующими маршрут без учета длительности выполнения задач. В результате пользователи вынуждены комбинировать несколько приложений, вручную сопоставляя адреса, интервалы времени и порядок посещения точек.
Подобный подход характеризуется высокой трудоемкостью и ростом вероятности ошибок при увеличении количества задач \cite{reshenie_zadach_planirovaniya2020}.

Объектом исследования является процесс планирования последовательности выполнения задач в городской среде с учетом пространственных
и временных параметров.

Предметом исследования являются алгоритмы маршрутизации и методы оптимизации порядка выполнения задач с временными окнами
в условиях ограниченных вычислительных ресурсов веб-приложения.

Целью выпускной квалификационной работы является разработка веб-приложения для автоматизированного формирования оптимальной последовательности выполнения задач с учетом географического положения, временных окон и длительности выполнения.

Для достижения поставленной цели необходимо решить следующие задачи:

\begin{itemize}
    \item проанализировать предметную область и существующие программные решения;
    \item исследовать алгоритмические подходы к маршрутизации с временными окнами;
    \item разработать архитектуру программной системы;
    \item реализовать серверную часть и алгоритм оптимизации маршрута
          с поддержкой дополнительных ограничений;
    \item разработать пользовательский интерфейс с визуализацией маршрута
          на карте, импортом и экспортом задач;
    \item реализовать интеграцию с внешними картографическими сервисами;
    \item провести тестирование разработанного решения;
    \item оценить производительность и масштабируемость системы.
\end{itemize}

Практическая значимость работы~--- единый инструмент планирования маршрута с временными окнами, доступный частным пользователям и малому бизнесу без коммерческой подписки.
